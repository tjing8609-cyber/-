知到自动播放脚本 - 使用说明
========================================

📦 项目简介
========================================

本项目是知到（智慧树）网页版自动播放器，支持：
✅ 自动播放视频课程
✅ 自动答题（有题目版本）
✅ 纯答题模式（智能答题，支持DeepSeek API）
✅ 多账号同时运行
✅ 智能卡顿检测与恢复
✅ 进度自动保存

🚀 快速开始（2种方式）
========================================

【方式1】双减bat文件启动（推荐）
-------------------
1. 打开 `启动/account1.json` 文件，填写账号密码
2. 设置运行模式：
   - mode: "video" → 视频播放模式（默认）
   - mode: "quiz_only" → 纯答题模式（需配置DeepSeek API）
3. 如果是视频模式，设置 course_type（1=无题目，2=有题目）
4. 如果是答题模式，设置 quiz_type（课程测试/章节测试等）
5. 双击 `启动/运行账号1.bat`

【方式2】命令行启动
-------------------
环境配置参考文档中的requirements.txt

在项目根目录（zhidao文件夹）执行：

# 视频播放模式（默认）
```
python code\zhidao_launcher.py --account 启动\account1.json
```

# 纯答题模式（需先将account.json中mode设为quiz_only）
```
python code\zhidao_launcher.py --account 启动\account1.json
```

⚠️ 注意：
- 必须在项目根目录（zhidao文件夹）下运行
- 路径必须包含 code\ 和 启动\ 前缀
- 不要直接运行 zhidao_web_auto_player_*.py


✨ 核心功能说明
========================================

1. 视频播放模式
   - 自动查找未观看的视频
   - 智能跳过已完成视频
   - 每次播完自动切换下一个

2. 自动答题（有题目版本）
   - 自动识别题目类型（单选/多选）
   - 自动提取正确答案
   - 自动选择并提交
   - ESC键关闭题目弹窗

3. 纯答题模式（新增）
   - DeepSeek AI智能答题
   - 支持单选、多选、判断题
   - 自动识别题型和选项
   - 启动时验证API连接
   - 支持课程测试/章节测试/期末考试

4. 智能卡顿恢复
   - 每10秒检测播放进度
   - 连续3次无进展自动恢复
   - 点击视频中央+暂停播放双重策略

5. 进度保存
   - 自动保存观看进度
   - 断点续播
   - 多账号独立进度


⚙️ 高级配置（可选）
========================================

【多账号配置】
-------------------
1. 复制 `启动/account.json` 为 `启动/account1.json`、`启动/account2.json` 等
2. 分别填写不同账号信息
3. 双击对应的 bat 文件启动

示例：
- 运行账号1.bat → 使用 account1.json
- 运行账号2.bat → 使用 account2.json
- 运行账号3.bat → 使用 account3.json


【课程模式切换】
-------------------
修改 account.json 中的 mode 和 course_type：

视频播放模式：
- mode: "video"  →  视频播放模式
- course_type: 1  →  无题目课程
- course_type: 2  →  有题目课程

纯答题模式：
- mode: "quiz_only"  →  纯答题模式
- quiz_type: "课程测试"  →  测试类型
- 必须配置DeepSeek API

脚本会自动选择对应版本运行！


【查看日志】
-------------------
日志文件位于 `log/` 文件夹：
- 无题目版本：zhidao_account1.log
- 有题目版本：zhidao_account1_quiz.log

打开日志文件可以看到详细的执行过程。


【查看进度】
-------------------
进度文件位于 `log/` 文件夹：
- progress_account1.json
- progress_account2.json
- progress_account3.json

包含：
- total_watched: 已观看视频数量
- total_quizzes: 已答题数量
- completed_videos: 已完成视频列表


📋 常见问题
========================================

Q1: 找不到 account.json 文件？
A1: 它在 `启动/` 文件夹中，打开后填写账号密码。

Q2: 脚本一直提示"未找到未观看视频"？
A2: 检查课程是否已全部完成，或者刷新页面重试。

Q3: 视频播放后一直卡住不动？
A3: 脚本会自动检测并恢复，等待10-30秒。如果仍然卡住，检查网络连接。

Q4: 题目无法自动答题？
A4: 确保 course_type 设置为 2，并且题库中有该题目的答案。

Q5: 多账号会不会冲突？
A5: 不会！每个账号有独立的日志文件和进度文件，互不干扰。

Q6: 日志文件太大怎么办？
A6: 脚本每20次运行会自动清理日志，保留最近5000行。

Q7: 纯答题模式API验证失败？
A7: 检查：
    1. API密钥是否正确
    2. API Base URL是否为https://api.deepseek.com（不含/anthropic）
    3. 网络连接是否正常
    4. 查看log/日志文件获取详细错误信息
