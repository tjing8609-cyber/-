知到自动播放脚本 - 使用说明

📦 项目简介
========================================

本项目是知到（智慧树）网页版自动播放器，支持：
✅ 自动播放视频课程
✅ 自动答题（有题目版本）
✅ 多账号同时运行
✅ 智能卡顿检测与恢复
✅ 进度自动保存

🚀 快速开始（3步启动）
========================================

【第一步】配置账号信息
-------------------
1. 打开 `启动/account.json` 文件
2. 填写你的账号和密码：
   ```json
   {
       "username": "你的手机号或学号",
       "password": "你的密码",
       "course_type": 2
   }
   ```
3. 保存文件

【第二步】选择课程类型
-------------------
修改 account.json 中的 course_type 字段：
- course_type: 1  →  无题目课程（自动播放视频）
- course_type: 2  →  有题目课程（自动播放+答题）


【第三步】启动脚本
-------------------
双击运行：
- 单账号：双击 `启动/运行账号1.bat`
- 多账号：双击 `启动/运行账号1.bat`、`启动/运行账号2.bat` 等


✨ 核心功能说明
========================================

1. 自动播放视频
   - 自动查找未观看的视频
   - 智能跳过已完成视频
   - 每次播完自动切换下一个

2. 自动答题（有题目版本）
   - 自动识别题目类型（单选/多选）
   - 自动提取正确答案
   - 自动选择并提交
   - ESC键关闭题目弹窗

3. 智能卡顿恢复
   - 每10秒检测播放进度
   - 连续3次无进展自动恢复
   - 点击视频中央+暂停播放双重策略

4. 进度保存
   - 自动保存观看进度
   - 断点续播
   - 多账号独立进度


⚙️ 高级配置（可选）
========================================

【多账号配置】
-------------------
1. 复制 `启动/account.json` 为 `启动/account1.json`、`启动/account2.json` 等
2. 分别填写不同账号信息
3. 双击对应的 bat 文件启动

示例：
- 运行账号1.bat → 使用 account1.json
- 运行账号2.bat → 使用 account2.json
- 运行账号3.bat → 使用 account3.json


【课程类型切换】
-------------------
修改 account.json 中的 course_type：
- course_type: 1  →  无题目课程
- course_type: 2  →  有题目课程

脚本会自动选择对应版本运行！


【查看日志】
-------------------
日志文件位于 `log/` 文件夹：
- 无题目版本：zhidao_account1.log
- 有题目版本：zhidao_account1_quiz.log

打开日志文件可以看到详细的执行过程。


【查看进度】
-------------------
进度文件位于 `log/` 文件夹：
- progress_account1.json
- progress_account2.json
- progress_account3.json

包含：
- total_watched: 已观看视频数量
- total_quizzes: 已答题数量
- completed_videos: 已完成视频列表


📋 常见问题
========================================

Q1: 找不到 account.json 文件？
A1: 它在 `启动/` 文件夹中，打开后填写账号密码。

Q2: 脚本一直提示"未找到未观看视频"？
A2: 检查课程是否已全部完成，或者刷新页面重试。

Q3: 视频播放后一直卡住不动？
A3: 脚本会自动检测并恢复，等待10-30秒。如果仍然卡住，检查网络连接。

Q4: 题目无法自动答题？
A4: 确保 course_type 设置为 2，并且题库中有该题目的答案。

Q5: 多账号会不会冲突？
A5: 不会！每个账号有独立的日志文件和进度文件，互不干扰。

Q6: 日志文件太大怎么办？
A6: 脚本每20次运行会自动清理日志，保留最近5000行。

⚠️ 注意事项
========================================

1. 账号安全
   - 使用完成后请清空 account.json 中的账号密码
   - 不要在公共场所使用
   - 不要分享包含账号密码的配置文件

2. 使用建议
   - 建议单个账号运行，避免资源占用过高
   - 多账号运行时，建议间隔5-10分钟启动
   - 运行期间保持网络稳定

3. 学习建议
   - 本脚本仅供学习交流使用
   - 请合理使用，不要过度依赖自动化
   - 建议配合实际学习，巩固知识点
