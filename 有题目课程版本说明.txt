========================================
知到自动播放器 - 有题目课程版本说明
========================================

版本:v2.0 (新版布局支持版)
日期:2025-11-17
作者:Qoder AI

一、功能概述
========================================

本版本专门用于处理带有题目弹窗的知到课程（课程类型2），与旧版（无题目课程）完全独立，互不干扰。

核心功能：
1. ✅ 自动登录
2. ✅ 人机验证等待处理
3. ✅ 课程查找与进入
4. ✅ 视频自动连续播放（新版布局特性）
5. ✅ 题目弹窗检测
6. ✅ 随机选择答案并提交
7. ✅ 自动关闭题目弹窗
8. ✅ **视频卡停检测与恢复（v1.1新增）**
9. ✅ 进度记录与统计

二、与旧版的区别
========================================

| 特性 | 旧版（无题目） | 新版（有题目） |
|------|---------------|---------------|
| 文件名 | zhidao_web_auto_player_final.py | zhidao_web_auto_player_with_quiz.py |
| 课程类型 | course_type: 1 | course_type: 2 |
| 布局类型 | 主区域列表/侧边栏 | 新版侧边栏 |
| 视频播放 | 手动点击每个视频 | 自动连续播放 |
| 题目处理 | 需手动关闭 | 自动随机回答 |
| 日志文件 | zhidao_accountX.log | zhidao_accountX_quiz.log |
| 进度文件 | progress_accountX.json | progress_accountX.json（共享） |

三、使用方法
========================================

方法一：使用智能启动器（推荐）
-------------------
1. 在 account.json 中设置 course_type:
   - course_type: 1 → 自动使用旧版（无题目）
   - course_type: 2 → 自动使用新版（有题目）

2. 运行批处理文件：
   双击 "运行账号1.bat"

3. 启动器会自动选择合适的版本

方法二：直接运行
-------------------
命令行运行：
python zhidao_launcher.py --account account1.json

或直接运行有题目版本：
python zhidao_web_auto_player_with_quiz.py --account account1.json

四、配置说明
========================================

account.json 示例：
```json
{
  "username": "你的账号",
  "password": "你的密码",
  "course_name": "课程名称",
  "course_type": 2,  // 1=无题目, 2=有题目
  "max_watch_minutes": 0,
  "use_sidebar_layout": true
}
```

关键参数：
- course_type: 2 → 启用有题目版本
- course_name: 课程名称（部分匹配即可）

五、题目处理机制
========================================

**1. 检测频率：**
   每10秒检查一次是否有题目弹窗

**2. 题目识别（v1.2增强）：**
   通过多种选择器识别题目弹窗
   - topic-item
   - subject-item
   - popTopicChoose
   - AI助教、出题 （新增）
   - 文本包含"题目"或"选择"
   - Element UI对话框中的单选框 （新增）
   - 只检测可见元素 （新增）

**3. 选项选择（v1.2优化）：**
   优先级顺序（从高到低）：
   1. input[@type='radio'] - 单选框（最优先）
   2. el-radio - Element UI单选框组件
   3. topic-item / subject-item - 题目项
   4. option - 通用选项
   
   特性：
   - 过滤不可见元素
   - 找到优先级最高的就停止
   - 显示找到的选项数量

**4. 回答策略（v1.3重大优化）：**
   智能答题 - 从 A 到 D 依次尝试，直到正确
   
   流程：
   ```
   开始答题
     ↓
   尝试选项 A
     ↓
   点击选项 + 提交（如有）
     ↓
   等待反馈（1.5秒）
     ↓
   检查是否"正确"？
     ├─ 是 → ✅ 成功，关闭弹窗
     │
     └─ 否 → ❌ 错误，尝试下一个
            ↓
        尝试选项 B
            ↓
          (重复流程)
            ↓
        尝试 C, D...
   ```
   
   特性：
   - ✅ 自动检测"正确"提示
   - ✅ 自动检测"错误"提示
   - ✅ 最多尝试4个选项
   - ✅ 找到正确答案后立即停止
   - ✅ 支持JavaScript点击备用方案

**5. 答案正确性检测（v1.3新增）：**
   
   正确标记：
   - 文本包含"正确"
   - 文本包含"√"
   - class包含'correct'或'success'
   - Element UI成功图标
   
   错误标记：
   - 文本包含"错误"
   - 文本包含"×"
   - class包含'error'或'wrong'
   - Element UI错误图标

**6. 关闭流程（v1.2增强）：**
   尝试多种关闭方式：
   a) 点击"关闭"按钮（新增）
   b) 点击Element UI关闭图标
   c) 点击对话框关闭按钮
   d) 点击通用close按钮
   e) 按ESC键（备用方案，新增）

**7. 统计记录：**
   - 本次运行回答题目数
   - 总计回答题目数

**8. 容错处理（v1.2新增）：**
   - 如果找不到选项，自动关闭弹窗
   - 如果点击失败，尝试关闭弹窗
   - 防止弹窗阻塞视频播放

六、视频卡停检测与恢复机制（v1.1新增）
========================================

**功能说明：**
知到平台可能存在防脚本机制，会自动暂停视频播放。本版本集成了
智能卡停检测与恢复机制，确保视频持续播放。

**1. 检测机制：**

检测频率：每10秒检查一次

检测指标：
- 视频是否处于暂停状态
- 视频进度是否停滞不前

卡停判断标准：
- 进度差值 < 1秒：计为无进展
- 连续3次无进展：触发恢复机制

**2. 恢复策略：**

策略1：点击视频中央区域（优先级最高）
```javascript
// 计算视频中心点坐标
var centerX = rect.left + rect.width / 2;
var centerY = rect.top + rect.height / 2;

// 创建鼠标点击事件
var clickEvent = new MouseEvent('click', {...});

// 点击中心区域
elem.dispatchEvent(clickEvent);
```

优势：
- 直接触发播放器的播放操作
- 绕过防脚本机制的自动暂停
- 比依赖播放按钮更可靠

策略2：暂停-播放刷新缓冲
```javascript
video.pause();  // 先暂停
setTimeout(function() {
    video.play();  // 500ms后播放
}, 500);
```

优势：
- 刷新视频缓冲区
- 解决网络卡顿问题
- 重新初始化播放状态

**3. 执行流程：**

```
开始监控视频
  ↓
每10秒检查一次
  ↓
获取当前进度：45秒
  ↓
对比上次进度：45秒
  ↓
差值 < 1秒 → 无进展计数+1
  ↓
连续3次无进展？
  ├─ 是 → 触发恢复
  │      ↓
  │   点击视频中央
  │      ↓
  │   暂停-播放操作
  │      ↓
  │   重置计数器
  │      ↓
  └─ 否 → 继续监控
       ↓
  进度恢复正常
```

1. 检查关闭按钮选择器

解决：
1. 检查account.json中的course_type
2. 确保值为1或2
3. 检查JSON格式是否正确
