========================================
知到自动播放脚本 - 使用说明
版本：v3.0 - 支持多实例 + PPT处理
========================================

【快速开始】

第1步：配置账号密码
-------------------
编辑 account.json 文件，填写您的账号和密码：

{
    "username": "你的账号",
    "password": "你的密码",
    "note": "请在运行脚本前填写您的账号和密码"
}

第2步：运行脚本
-------------------
方式1：命令行运行
    python zhidao_web_auto_player_final.py

方式2：双击批处理文件（推荐）
    双击 "运行账号1.bat" 或其他.bat文件

第3步：完成人机验证
-------------------
如果出现人机验证，请在浏览器中手动完成
程序会自动检测并继续运行


【程序功能】

基础功能：
✓ 自动清理旧的调试文件（PNG和HTML）
✓ 自动从 account.json 读取账号密码
✓ 自动登录知到网站
✓ 自动查找课程
✓ 自动识别未观看视频
✓ 自动跳过已完成视频
✓ 自动切换到新窗口播放
✓ 自动点击视频中央启动播放
✓ 自动检测和恢复卡顿
✓ 自动应对网站防脚本暂停
✓ 自动保存进度记录

新增功能（v3.0）：
✅ 识别部分观看的视频（8%, 17%等）
✅ 以实际视频进度为准，不是等待时间
✅ 持续播放直到所有视频100%完成
✅ 自动处理PPT文件（点击进入→5秒→返回）
✅ 支持多账号同时运行（多实例）
✅ 命令行参数灵活配置


【配置文件说明】

account.json - 账号密码配置（必需）
-------------------
{
    "username": "你的账号",
    "password": "你的密码",
    "course_name": "中国近现代史纲要",
    "note": "请填写账号、密码和课程名称"
}

每次运行前填写，使用后可清空（安全考虑）
注意：v3.1起course_name已从 config.json 移至 account.json，
      支持每个账号配置不同课程


config.json - 程序配置（可选）
-------------------
{
    "min_watch_percentage": 0.95,
    "max_videos_per_run": 999,
    "captcha_timeout": 300,
    "enable_notifications": true
}

参数说明：
- min_watch_percentage: 最小观看百分比（0.95 = 95%）
- max_videos_per_run: 每次运行最多播放视频数（999=持续播放）
- captcha_timeout: 人机验证等待超时时间（秒）
- enable_notifications: 是否启用通知

注意：course_name 已从此文件移至 account.json（v3.1+）


【多实例运行】

支持同时运行多个账号：

方法1：使用不同的账号配置文件
    python zhidao_web_auto_player_final.py --account account1.json
    python zhidao_web_auto_player_final.py --account account2.json
    python zhidao_web_auto_player_final.py --account account3.json

方法2：双击批处理文件（推荐）
    双击 "运行账号1.bat"
    双击 "运行账号2.bat"
    双击 "运行账号3.bat"

注意事项：
- 每个账号使用独立的配置文件
- 进度文件自动分离（progress_account1.json等）
- 日志文件自动分离（zhidao_account1.log等）
- 建议时间错开5-10分钟启动
- 最多同时运行2-3个实例


【注意事项】

运行期间：
1. 不要手动关闭浏览器窗口
2. 遇到人机验证请手动完成
3. 观察日志输出，检查运行状态
4. 程序会自动处理视频卡顿（连续4次无进展后自动恢复）

文件管理：
1. 每次运行前填写 account.json
2. 程序会自动清理旧的调试文件
3. 不要删除 account.json 文件
4. 进度文件会自动保存，支持断点续播

视频识别：
1. 绿色勾标记 → 已完成，跳过
2. 100% → 已完成，跳过
3. 8%, 17%等部分百分比 → 继续播放
4. 空心圆 → 未开始，播放
5. .pptx/.ppt文件 → 所有视频完成后处理


【常见问题】

问题1：找不到 account.json
解决：创建 account.json 文件并填写账号密码

问题2：账号或密码为空
解决：在 account.json 中填写正确的账号和密码

问题3：JSON格式错误
解决：检查JSON格式，确保使用英文双引号和正确的逗号

问题4：视频一直卡住
解决：程序会自动恢复（连续4次无进展后点击视频中央）；检查网络连接

问题5：找不到video元素
解决：查看自动保存的调试文件（*.png 和 *.html）

问题6：无法识别部分观看的视频
解决：确保使用最新版本，已支持 8%, 17% 等部分百分比识别

问题7：多个实例进度冲突
解决：使用不同的 --account 参数，进度文件会自动分离


【安全建议】

1. 使用完成后清空 account.json 中的账号密码
2. 如果使用Git，将 account.json 添加到 .gitignore
3. 不要在公共场所使用或分享包含账号密码的文件
