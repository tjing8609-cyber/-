  - 所有带时间戳的 .html 文件（*_202*.html）

  - 脱敏显示账号：176****12


3. 新窗口自动切换
-------------------
问题：点击视频后打开新窗口，程序停留在旧窗口找不到video元素

解决方案：
  1. 记录点击前的窗口句柄
  2. 点击视频后检测窗口数量变化
  3. 如果增加了新窗口，自动切换到新窗口
  4. 播放完成后关闭新窗口并返回原窗口

关键代码：
  original_windows = driver.window_handles
  element.click()
  if len(current_windows) > len(original_windows):
      new_window = [w for w in current_windows if w not in original_windows][0]
      driver.switch_to.window(new_window)


4. 视频完成状态检测
-------------------
检测方法：查找特定的class名称
  - 已完成：class="iconfont zhihuishu-wancheng"（绿色勾✓）
  - 未完成：class="iconfont zhihuishu-weikaishi"（空心圆○）
  - 100%：文本包含"100%"
  - 部分观看：正则匹配 1%-99% 百分比

实现位置：is_video_completed() 方法

过滤规则：
  - 跳过：包含“作业”字样
  - 跳过：已完成（有绿色勾✓）
  - 跳过：100%完成
  - 跳过：不是.mp4文件
  - 跳过（稍后处理）：.pptx/.ppt文件
  - 继续播放：8%, 17%等部分百分比
  - 选择：未完成的.mp4视频


5. 视频播放启动策略
-------------------
策略1：点击视频中央黑色区域（优先，最可靠）
  - 计算video元素的中心坐标
  - 创建真实的MouseEvent点击事件
  - 触发中心位置元素的点击

策略2：JavaScript直接播放（辅助）
  - video.play()
  - 作为兜底方案

实现位置：click_video_center() 方法


6. 视频卡顿检测和恢复
-------------------
检测机制：
  - 每10秒检查一次播放进度
  - 如果进度差值 < 1秒，计数+1
  - 连续4次无变化判定为卡顿（从3次调整为4次）

恢复策略：
  策睥1：点击视频中央（应对自动暂停）
    - 模拟真实用户点击
    - 触发播放器恢复
  
  策睥2：暂停-播放（刷新缓冲）
    - video.pause()
    - 等待500ms
    - video.play()

实现位置：simulate_watching() 方法


6. 视频卡顿检测和恢复
-------------------
检测机制：
  - 每10秒检查一次播放进度
  - 如果进度差值 < 1秒，计数+1
  - 连续4次无变化判定为卡顿（从3次调整为4次）

恢复策略：
  策睥1：点击视频中央（应对自动暂停）
    - 模拟真实用户点击
    - 触发播放器恢复
  
  策睥2：暂停-播放（刷新缓冲）
    - video.pause()
    - 等待500ms
    - video.play()

实现位置：simulate_watching() 方法


7. 实际视频进度检测（v3.0）
-------------------
功能：以视频实际播放进度为准，而非程序等待时间

关键逻辑：
  - 每次循环开始获取 video.currentTime
  - 判断 video_progress >= watch_time
  - 达到目标进度立即退出
  - 超时保护：最多等待 2×watch_time

优势：
  - 准确反映视频实际观看状况
  - 避免因网络卡顿导致的误判
  - 支持断点续播（部分百分比）

实现位置：simulate_watching() 方法


8. PPT文件处理（v3.0）
-------------------
功能：在所有视频播放完成后，自动处理PPT文件

处理流程：
  1. 查找所有包含 .ppt/.pptx 的元素
  2. 过滤已完成的PPT
  3. 点击PPT进入页面
  4. 等待5秒
  5. 关闭窗口/后退返回课程列表
  6. 记录已完成PPT

实现位置：
  - find_unwatched_ppts() 方法
  - play_ppt() 方法
  - run() 方法中在视频播放后调用


9. 多实例支持（v3.0）
-------------------
功能：支持同时运行多个账号

核心机制：
  - 命令行参数 --account 指定账号配置文件
  - 基于账号文件名生成独立进度文件
  - 基于账号文件名生成独立日志文件

文件映射：
  account1.json → progress_account1.json, zhidao_account1.log
  account2.json → progress_account2.json, zhidao_account2.log
  account3.json → progress_account3.json, zhidao_account3.log

命令示例：

  python zhidao_web_auto_player_final.py --account account2.json

  - main() 函数：argparse 参数解析

3. 常见错误排查
-------------------
错误：no such element: Unable to locate element: {"method":"xpath","selector":"//video"}
原因：video元素在新窗口中，程序未切换窗口
解决：已实现自动窗口切换

错误：Cannot read properties of null (reading 'duration')
原因：JavaScript访问了null对象
解决：已使用安全模式：document.querySelector('video') ? video.duration : null

错误：账号配置文件 account.json 不存在
原因：account.json文件被删除或移动
解决：创建account.json文件并填写账号密码

错误：账号或密码为空
原因：account.json中未填写账号密码
解决：在account.json中填写正确的账号和密码

错误：JSON格式错误
原因：JSON格式不正确
解决：检查引号、逗号、括号是否正确

【技术细节】

1. 窗口切换实现
-------------------
# 记录原始窗口
original_windows = driver.window_handles
original_window = driver.current_window_handle

# 点击元素
element.click()

# 检测新窗口
current_windows = driver.window_handles
if len(current_windows) > len(original_windows):
    new_window = [w for w in current_windows if w not in original_windows][0]
    driver.switch_to.window(new_window)

# 完成后返回
driver.close()  # 关闭新窗口
driver.switch_to.window(original_window)  # 返回原窗口


2. 点击视频中央实现
-------------------
# 获取video元素
video = driver.find_element(By.XPATH, "//video")

# JavaScript点击中心
driver.execute_script("""
    var video = arguments[0];
    var rect = video.getBoundingClientRect();
    var centerX = rect.left + rect.width / 2;
    var centerY = rect.top + rect.height / 2;
    
    // 创建点击事件
    var clickEvent = new MouseEvent('click', {
        view: window,
        bubbles: true,
        cancelable: true,
        clientX: centerX,
        clientY: centerY
    });
    
    // 获取中心位置的元素并点击
    var elem = document.elementFromPoint(centerX, centerY);
    if (elem) {
        elem.dispatchEvent(clickEvent);
    }
""", video)


3. 安全JavaScript调用
-------------------
# 获取视频时长
duration = driver.execute_script(
    "return document.querySelector('video') ? document.querySelector('video').duration : null"
)

# 检测播放状态
is_playing = driver.execute_script(
    "return document.querySelector('video') ? !document.querySelector('video').paused : false"
)

# 获取播放进度
current_time = driver.execute_script(
    "return document.querySelector('video') ? document.querySelector('video').currentTime : 0"
)


4. 卡顿检测逻辑
-------------------
# 每10秒检查一次
if int(elapsed) % 10 == 0:
    current_progress = get_video_progress()
    
    # 检查进度变化
    if abs(current_progress - last_progress_check) < 1:
        no_progress_count += 1
        
        if no_progress_count >= 3:
            # 触发恢复
            # 1. 点击视频中央
            # 2. 暂停-播放
            no_progress_count = 0
    else:
        no_progress_count = 0


【性能优化】

1. 智能等待
-------------------
使用WebDriverWait代替固定sleep
设置合理的超时时间
减少不必要的等待


2. 减少干扰行为
-------------------
降低随机滚动频率：30% → 20%
减小滚动幅度：±200px → ±100px
移除可能影响播放的随机点击


3. 提前结束
-------------------
实时检测视频实际播放进度
达到目标时长立即结束
避免浪费时间
