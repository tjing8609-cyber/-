错误类型: KeyError: 'total_watched'
错误位置: zhidao_web_auto_player_final.py, line 2237

【所有可能的问题】

1. 进度文件相关问题
   ● 进度文件损坏或JSON格式错误
   ● 进度文件不存在（首次运行）
   ● 进度文件缺少必需的键（如 total_watched, completed_videos, last_update）
   ● 旧版本进度文件与新版本代码不兼容
   ● 进度文件权限不足，无法读取或写入
   ● 进度文件编码问题（BOM、UTF-8等）

2. ChromeDriver相关问题
   ● ChromeDriver未安装或下载失败
   ● ChromeDriver版本与Chrome浏览器版本不匹配
   ● 网络问题导致自动下载失败
   ● 系统PATH环境变量未配置chromedriver
   ● webdriver-manager缓存损坏
   ● SSL证书验证失败

3. 账号配置问题
   ● 账号配置文件不存在（account1.json等）
   ● 账号或密码为空
   ● JSON格式错误（缺少引号、逗号等）
   ● 配置文件编码问题
   ● 必需字段缺失（username, password, course_name等）

4. 日志文件问题
   ● 日志目录不存在
   ● 日志文件权限不足
   ● 磁盘空间不足
   ● 日志文件过大导致性能问题

5. 浏览器相关问题
   ● Chrome浏览器未安装
   ● Chrome浏览器版本过旧
   ● 浏览器被手动关闭
   ● 浏览器崩溃或无响应
   ● 浏览器扩展冲突

6. 网络连接问题
   ● 无法访问知到网站
   ● 网络超时
   ● 防火墙阻止连接
   ● 代理配置问题

7. 登录相关问题
   ● 账号密码错误
   ● 人机验证未完成
   ● 登录页面元素变化（网站更新）
   ● 验证码识别失败
   ● 账号被封禁

8. 课程查找问题
   ● 课程名称配置错误
   ● 课程URL失效
   ● 课程未加载完成
   ● 页面布局变化（侧边栏/主区域）

9. 视频播放问题
   ● 视频元素未找到
   ● 视频加载超时
   ● 视频播放卡顿
   ● 视频进度检测失败
   ● 弹窗干扰（题目、提示等）

10. 依赖包问题
    ● selenium版本不兼容
    ● webdriver-manager版本不兼容
    ● Python版本不支持（需要3.7+）
    ● 缺少必需的依赖包

【常见报错信息及解决方案】

1. KeyError: 'total_watched'
   原因: 进度文件格式不正确或缺少字段
   解决: 
   - 删除 log/progress_*.json 文件，重新运行
   - 或手动修复进度文件，添加缺失的键

2. NoSuchDriverException
   原因: ChromeDriver未找到
   解决:
   - 检查网络连接
   - 运行: pip install --upgrade selenium webdriver-manager
   - 手动下载chromedriver.exe

3. FileNotFoundError: account1.json
   原因: 账号配置文件不存在
   解决:
   - 基于account.json.template创建account1.json
   - 填写账号密码

4. JSONDecodeError
   原因: JSON配置文件格式错误
   解决:
   - 检查JSON语法（引号、逗号、括号）
   - 使用JSON验证工具检查

5. TimeoutException
   原因: 页面加载超时
   解决:
   - 检查网络连接
   - 增加等待时间
   - 手动刷新页面

6. NoSuchElementException
   原因: 页面元素未找到
   解决:
   - 网站页面可能更新
   - 等待页面加载完成
   - 检查选择器是否正确

7. SessionNotCreatedException
   原因: ChromeDriver与Chrome版本不匹配
   解决:
   - 更新Chrome浏览器
   - 重新下载对应版本的ChromeDriver
   - 清除webdriver-manager缓存

8. PermissionError
   原因: 文件或目录权限不足
   解决:
   - 以管理员权限运行
   - 检查文件/目录权限

9. UnicodeDecodeError
   原因: 文件编码问题
   解决:
   - 确保文件使用UTF-8编码
   - 删除BOM标记

10. WebDriverException: chrome not reachable
    原因: 浏览器进程异常
    解决:
    - 重启程序
    - 结束Chrome进程
    - 检查Chrome是否正常

【当前问题的解决方案】

针对 KeyError: 'total_watched' 错误：

方案1: 删除进度文件（推荐）
  删除 log 目录下的所有 progress_*.json 文件
  程序会自动创建新的进度文件

方案2: 手动修复进度文件
  打开 log/progress_account1.json
  确保包含以下字段：
  {
    "completed_videos": [],
    "total_watched": 0,
    "last_update": null,
    "run_count": 0
  }

方案3: 代码层面修复
  在代码中添加键存在性检查
  使用 .get() 方法代替直接访问
  例如: self.progress.get('total_watched', 0)

【预防措施】

1. 定期备份配置文件和进度文件
2. 更新前检查兼容性
3. 保持网络连接稳定
4. 及时更新Chrome浏览器和依赖包
5. 使用日志文件排查问题
6. 不要在运行时手动关闭浏览器
7. 确保有足够的磁盘空间
8. 定期清理日志文件
