========================================

【更新日期】2025-10-29

========================================
一、核心改进
========================================

优化目标：
----------------------------------------
减少频繁的元素查找操作，提升处理速度

改进点：
  1. 查找频率：从每次查找一个 → 每10次查找一次
  2. 刷新频率：从每5次刷新 → 每10次刷新
  3. 元素缓存：使用列表缓存查找结果


========================================
二、技术实现
========================================

视频处理优化
----------------------------------------
旧版（v3.2.1）：
  - 每次播放前都查找一次
  - 每5次刷新一次
  - 100个视频需要查找100次

新版（v3.3）：
  - 每10次查找一次，缓存结果
  - 每10次刷新一次
  - 100个视频只需查找10次

代码实现：
```python
unwatched_videos = []  # 缓存列表

while attempt < max_videos:
    # 每10次刷新一次
    if items_processed_since_refresh >= 10:
        driver.refresh()
        items_processed_since_refresh = 0
        unwatched_videos = []  # 清空缓存
    
    # 每10次查找一次（或缓存为空时）
    if not unwatched_videos or (attempt - 1) % 10 == 0:
        unwatched_videos = find_unwatched_videos()
        print(f"找到 {len(unwatched_videos)} 个视频")
    else:
        print(f"使用缓存（剩余 {len(unwatched_videos)} 个）")
    
    # 从缓存中取出第一个播放
    video = unwatched_videos.pop(0)
    play_video(video)
    items_processed_since_refresh += 1
```


PPT处理优化
----------------------------------------
同样的优化策略：

```python
unwatched_ppts = []  # 缓存列表

while ppt_attempt < max_ppt_attempts:
    # 每10次刷新一次
    if items_processed_since_refresh >= 10:
        driver.refresh()
        items_processed_since_refresh = 0
        unwatched_ppts = []  # 清空缓存
    
    # 每10次查找一次（或缓存为空时）
    if not unwatched_ppts or (ppt_attempt - 1) % 10 == 0:
        unwatched_ppts = find_unwatched_ppts()
        print(f"找到 {len(unwatched_ppts)} 个PPT")
    else:
        print(f"使用缓存（剩余 {len(unwatched_ppts)} 个）")
    
    # 从缓存中取出第一个处理
    ppt = unwatched_ppts.pop(0)
    play_ppt(ppt)
    items_processed_since_refresh += 1
```

========================================
四、缓存安全性
========================================

Q1：缓存会导致元素过期吗？
----------------------------------------
A：不会。因为：
   1. 刷新时会清空缓存（unwatched_videos = []）
   2. 刷新后重新查找，元素是最新的
   3. 使用pop(0)逐个取出，不会重复使用

关键代码：
```python
if items_processed_since_refresh >= 10:
    driver.refresh()
    unwatched_videos = []  # ✅ 清空缓存
```


Q2：如果处理中途失败怎么办？
----------------------------------------
A：使用pop(0)从列表中取出元素：
   - 成功：元素已从列表移除
   - 失败：元素已从列表移除，进度文件会跳过
   - 下次循环继续处理列表中剩余的


Q3：为什么是每10次而不是其他数字？
----------------------------------------
A：经过测试，10次是最佳平衡点：
   
   每5次：查找还是有点频繁
   每10次：✅ 性能和稳定性平衡最佳
   每20次：刷新间隔太长，可能状态不同步
   
   刷新间隔 = 查找间隔 = 10次
