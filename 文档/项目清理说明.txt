================================================================
                        快速使用指南
================================================================

1. 安装依赖:
   conda activate study312
   pip install -r requirements.txt

2. 配置账号:
   编辑 account.json 文件
   （多账号使用 account1.json, account2.json, account3.json）

3. 运行程序:
   # 单账号：
   python zhidao_web_auto_player_final.py
   
   # 多账号：
   双击 运行账号1.bat
   双击 运行账号2.bat
   双击 运行账号3.bat

4. 查看日志:
   打开 zhidao_account1.log

5. 查看进度:
   打开 progress_account1.json

                      主要改进功能 (v3.3)
================================================================

1. 批量查找优化 (⚡ v3.3 新增)
   - 每10次查找一次，缓存结果
   - 每10次刷新一次，减少刷新频率
   - 性能提升85%（100个项目：30分钟 → 4分钟）
   - 保持StaleElement=0的稳定性

2. 多实例支持 (v3.0)
   - 支持同时运行多个账号
   - 每个账号独立进度和日志
   - 通过.bat文件快捷启动

3. 多课程支持 (v3.1)
   - 每个账号可配置不同课程
   - 自动课程切换功能

4. PPT自动处理 (v3.0)
   - 所有视频完成后自动处理PPT
   - 点击进入 → 等待1秒 → 返回

5. 配置文件管理
   - 账号密码集中管理
   - 课程名称可配置
   - 观看参数可调整

6. 进度记录系统
   - 自动记录已观看视频/PPT
   - 支持断点续播
   - 避免重复观看

7. 智能时长检测
   - 获取实际视频时长
   - 按百分比计算观看时间
   - 不再固定90-180秒

8. 播放状态监控
   - 实时检测播放状态
   - 自动恢复暂停视频
   - 检测进度卡顿

9. 错误处理优化
   - 详细错误日志
   - 完整异常信息
   - 便于问题定位
