【技术实现】

1. 查找PPT文件
-------------------
方法：find_unwatched_ppts()

查找策略：
  - 滚动页面加载所有内容（5次滚动到底部）
  - 查找包含 .ppt 或 .pptx 的元素
  - XPath选择器：//*[contains(text(), '.ppt')]

去重处理：
  - 使用set存储已见文本
  - 避免重复处理同一PPT

过滤条件：
  - 已完成PPT（绿色勾或100%）
  - 已记录PPT（progress.json中的completed_ppts）
  - 不可见或不可用的元素

返回值：
  [
    {'element': WebElement, 'text': 'PPT标题'},
    {'element': WebElement, 'text': 'PPT标题2'},
    ...
  ]


2. 处理单个PPT/PDF
-------------------
方法：play_ppt(ppt_info)

处理步骤：

步顂1：记录当前窗口

  driver.execute_script("scrollIntoView", element)
  element.click()

步骤3：检测新窗口

  if len(current_windows) > len(original_windows):

      driver.switch_to.window(new_window)

步霤4：等待1秒

步骤5：返回课程列表
  方式1：有新窗口 → 关闭新窗口，切换回原窗口
  方式2：无新窗口 → 浏览器后退

步骤6：记录已完成PPT
  progress['completed_ppts'].append(text)
  save_progress()

【常见问题】

问题1：为什么PPT要等待1秒？
-------------------
答：1秒是给系统记录学习行为的时间。虽然我们不需要实际阅读PPT内容，
    但需要让系统有足够时间标记该PPT为“已学习”状态。

    时间选择：
    - 太短（0秒）：可能无法成功标记
    - 太长（5秒+）：浪费时间
    - 1秒：经测试是更快速的合理选择


问题2：PPT和视频的处理顺序能否调换？
-------------------
答：不建议。原因：
    1. 视频是课程的核心内容，优先级更高
    2. 先处理视频可以更早完成主要学习任务
    3. PPT处理失败不影响视频完成状态
    4. 符合正常的学习习惯


问题3：PPT处理失败会怎样？
-------------------
答：程序会：
    1. 记录错误日志
    2. 跳过该PPT继续处理下一个
    3. 不影响已完成的视频
    4. 下次运行会重试失败的PPT


问题4：如何判断PPT是否处理成功？
-------------------
答：检查方法：
    1. 查看日志：有"✅ PPT处理完成"
    2. 查看进度文件：progress_*.json 中的 completed_ppts 数组
    3. 网页上查看：PPT应该有绿色勾或100%标记


问题5：PPT可以单独处理吗？
-------------------
答：目前不支持单独处理PPT。PPT处理是在所有视频完成后自动执行的。
    如果只想处理PPT，可以：
    1. 确保所有视频已100%完成
    2. 运行程序，会自动跳过视频直接处理PPT


问题6：多实例运行时PPT会冲突吗？
-------------------
答：不会冲突。原因：
    1. 每个实例使用独立的进度文件
    2. completed_ppts 数组独立存储
    3. 不同账号处理不同课程的PPT

【性能优化】

1. 智能滚动
-------------------
- 只滚动5次（而非无限滚动）
- 每次等待2秒（给予加载时间）
- 滚动后回到顶部


2. 去重处理
-------------------
- 使用set避免重复
- 检查进度文件跳过已处理
- 减少不必要的操作


3. 快速退出
-------------------
- 等待5秒后立即返回
- 不等待额外的加载时间
- 提高处理效率

| 对比项         | 视频处理         | PPT处理          |
+----------------+------------------+------------------+
| 文件类型       | .mp4             | .ppt, .pptx      |

【代码示例】

完整的PPT处理代码片段：

# 查找未观看PPT
unwatched_ppts = self.find_unwatched_ppts()

if unwatched_ppts:
    ppts_processed = 0
    
    for idx, ppt in enumerate(unwatched_ppts):
        self.logger.info(f"\n=== 处理PPT {idx + 1}/{len(unwatched_ppts)} ===")
        
        # 处理单个PPT
        if self.play_ppt(ppt):
            ppts_processed += 1
            self.logger.info(f"✅ 成功处理第 {ppts_processed} 个PPT")
        else:
            self.logger.warning(f"⚠️ 处理PPT失败")
        
        # 随机延迟
        self.smart_wait()
    
    self.logger.info(f"✅ PPT处理完成，共处理 {ppts_processed} 个PPT")
else:
    self.logger.info("✅ 没有找到未观看PPT")
