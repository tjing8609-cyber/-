📦 功能特性
-----------------------------------------------------------------
✅ 完全独立的exe应用
✅ 内置便携版Chrome浏览器
✅ 无需安装Python环境
✅ 无需安装Chrome浏览器
✅ 解压即用，开箱即用

📋 打包前准备
-----------------------------------------------------------------
1. 确保已安装Python 3.8+
2. 确保已安装所有依赖：pip install -r 文档/requirements.txt
3. 确保已安装PyInstaller：pip install pyinstaller

🌐 步骤1：下载便携版Chrome（约155MB）
-----------------------------------------------------------------
执行命令：
    python download_chrome_portable.py

说明：
- 会自动下载Chrome 131.0.6778.86版本
- 下载文件约155MB，需要几分钟
- 下载完成后会生成chrome-portable文件夹
- 如果下载失败，可以使用国内镜像

📦 步骤2：执行打包
-----------------------------------------------------------------
执行命令：
    python build_simple.py

说明：
- 打包过程约需3-5分钟
- 会自动将Chrome集成到exe中
- 最终生成文件约300-400MB（包含Chrome）

📂 步骤3：发布
-----------------------------------------------------------------
发布目录：
    dist/知到自动播放器/

包含文件：
├── 知到自动播放器.exe          ← 主程序
├── _internal/                  ← 内部文件（必需）
│   ├── chrome-portable/        ← 便携版Chrome
│   ├── code/                   ← Python脚本（已编译）
│   ├── 启动/                   ← 配置文件
│   ├── 文档/                   ← 说明文档
│   └── [其他运行时文件]
├── account.json.template       ← 配置模板
└── 使用说明.txt               ← 用户说明

发布方式：
- 将整个"知到自动播放器"文件夹打包成ZIP
- 分发给用户解压后直接使用
- 用户只需双击exe即可运行

⚠️ 重要提示
-----------------------------------------------------------------
1. 必须保持文件夹结构完整
2. 不要单独发布exe文件
3. _internal文件夹必须与exe在同一目录
4. chrome-portable文件夹大约200MB

📊 最终文件大小
-----------------------------------------------------------------
- Chrome浏览器：约200MB
- Python运行时：约100MB
- 项目代码：约5MB
- 总大小：约300-350MB

-----------------------------------------------------------------
1. 解压知到自动播放器.zip
2. 双击"知到自动播放器.exe"
3. 填写账号配置
4. 点击"开始运行"
